### 1. JWT


+ JWT is a digitally signed token that proves a user's identity. It’s like a digital passport.
+ JWTs are Base64URL encoded, not encrypted.
+ you cannot extract the data (payload) from the signature in a JWT Because the signature is a hash, not an encoding
+ but we can read data from header and payload since they are Base64URL-encoded, not encrypted
+ Anyone can read them, but only the server can verify the signature.
+ Hashing (Signature) != Encryption != Encoding
+ To keep data private, use JWE (JSON Web Encryption) instead of plain JWT.
+ we use jwt in http, and like http has header and payload
+ Common Algorithms: 
    1. HS256 (HMAC with SHA-256) 
    2. HS512 (HMAC with SHA-512) 
    3. RS256 (RSASSA-PKCS1-v1_5 using SHA-256) 
    4. RS512 (RSASSA-PKCS1-v1_5 using SHA-512) 
    5. ES256

+ a JWT is look like this: `xxxxx.yyyyy.zzzzz` --> HEADER.PAYLOAD.SIGNATURE
+ it has 3 parts (all Base64 encoded):
    1. Header – type of token and signing algorithm
    2. Payload – user data (claims)
    3. Signature – verifies that the token is untampered and hasn’t been altered or forged.


```js
// 1. Header
{
  "alg": "HS256",
  "typ": "JWT"
}
// 2. Payload                     // the date is hashed with the algorithm specified in the header
{                                 // 
  "sub": "1234567890",
  "name": "John Doe",
  "admin": true,
  "iat": 1516239022              // Claims (Issued at =iat)
}
// 3. Signature                 // The Signature is generated like this
HMACSHA256(                     // It’s generated by hashing the header and payload together with a secret key
  base64UrlEncode(header) + "." + base64UrlEncode(payload),
  mysecretkey123              
)
```

| Feature     | **Hashing (Signature)** | **Encoding (Header/Payload)** | **Encryption (Secure Data)** |
| ----------- | ----------------------- | ----------------------------- | ---------------------------- |
| Reversible? | ❌ No                    | ✅ Yes                         | ✅ Yes (with key)             |
| Purpose     | Verify integrity        | Make data compact/URL-safe    | Keep data secret             |
| Example     | HMACSHA256              | Base64URL                     | AES, RSA                     |
