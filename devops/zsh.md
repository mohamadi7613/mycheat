

# ZSH



| Shell       | Main Strength             | POSIX Compatible | Default on             | Notes                    |
| ----------- | ------------------------- | ---------------- | ---------------------- | ------------------------ |
| **Bash**    | Compatibility & ubiquity  | ✅                | Linux                  | Simple, reliable         |
| **Zsh**     | Extensible, fast, pretty  | ✅                | macOS (since Catalina) | Great with Oh My Zsh     |
| **Fish**    | User-friendly, modern     | ❌                | None                   | Best for interactive use |
| **Ksh**     | Traditional Unix shell    | ✅                | Some Unix              | Stable, old-school       |
| **Tcsh**    | C-style scripting         | ❌                | BSD                    | Outdated but still used  |
